# Codex Trajectory plugin

This directory is the installable Codex plugin. Repository-level installation, privacy, interface, development, and attribution documentation lives in the [project README](../../README.md).

The MCP runtime reads only authorized local Codex session roots, validates legacy and paginated rollout lineages, excludes linked files and inherited subagent prefixes, and defaults to safe summaries. Use the plugin through its bundled Skill or the `list_codex_sessions`, `get_codex_trajectory`, and `show_codex_trajectory` tools. The viewer also has an adaptive live window backed by an app-only safe-summary update tool: Codex gets a full-height side panel with frozen task totals, an upper-right remaining-quota badge when official rate-limit windows are recorded, one-click and optional quota-threshold stop controls, and a scrolling per-record Token stream whose compact rows group Total, Input, and Output usage, while regular Chromium pages can use native video PiP. In the standard Apps surface the controls post a model-mediated safe-shutdown request; in the configured Browser surface they pause an active Goal and then interrupt the bound App Server turn directly. Manual Stop rearms for a later running turn, while automatic Stop stays latched across later turns in the same quota cycle so `/goal` continuation cannot create an interrupt loop; quota recovery, a window reset, or a guard configuration change rearms it. Transient automatic failures retry, and selecting a different trajectory disables stopping. An experimental off-by-default setting can run a loopback-only CDP watcher that injects a trajectory entry after `Full access`; clicking it opens the same complete trajectory interface as a tokenized Codex in-app Browser tab for the selected task without changing the composer, posting a message, invoking the model, or covering the Environment/Changes panel. Persistent `client-new-thread:*` sidebar keys are resolved to the canonical App Server UUID before opening, and the shortcut remains disabled until that identity is available. The Browser page follows Codex's System, Light, and Dark appearance choices by synchronizing a fixed allowlist of computed host colors, and its interactive fallback exposes stop controls through a session-matched, fixed-intent App Server Goal-pause plus `turn/interrupt` path that cannot accept arbitrary prompts or touch composer drafts and attachments. Routine state polls omit turn history, and stop requests pass the already-bound turn directly to the stop sequence, so very large tasks no longer block on full-history materialization; a rejected stale candidate is invalidated and receives one full bootstrap before retry. Each updated MCP runtime start reconciles the opt-in and safely replaces a verified older watcher process. It still defaults to safe summary. Its private setting tool writes only plugin-owned configuration, settings/status reads reject linked or oversized files, and all trajectory tools remain read-only. Neither path launches a standalone app. Protocol, projection, privacy, and resource limits are documented in the [interface reference](../../docs/interface.md).
