# Codex Trajectory plugin

**English** · [简体中文](#简体中文)

**Version 1.0.0** · October 2, 2026 · [Changelog](../../CHANGELOG.md#100---2026-10-02)

View local Codex task history as an interactive timeline and event ledger, with timing, tokens, estimated costs, and live activity.

Open **…** in Codex's left toolbar and choose **Codex Trajectory** for a fullscreen viewer; you can pin it to the toolbar. You can also choose **+ → More tools… → Plugins and MCPs → Codex Trajectory** in the task's right panel. Both native entries open without a model turn. Valid task context opens that exact task's safe summary; unavailable context shows a local task selector. Full details require confirmation, and live views always use safe summaries. Source logs remain unchanged.

After updating an existing installation, fully quit and reopen Codex to load the new entries.

See the [English README](../../README.md) for installation, screenshots, usage, and privacy. Technical details are in the [interface reference](../../docs/interface.md) and [native viewer guide](../../docs/native-viewer.md).

## 简体中文

**版本 1.0.0** · 2026 年 10 月 2 日 · [更新日志](../../CHANGELOG.md#100---2026-10-02)

将本地 Codex 任务历史展示为交互时间轴和事件账本，查看耗时、Token、估算费用和实时活动。

在 Codex 左侧工具栏的 **…** 应用列表中打开 **Codex Trajectory**，进入全屏查看器，并可将其固定到工具栏。也可在任务右侧面板中选择 **+ → More tools… → Plugins and MCPs → Codex Trajectory**。两个原生入口都不触发模型对话。有有效任务上下文时，精确展示该任务的安全摘要；上下文不可用时，显示本地任务选择器。完整详情需要确认，实时视图始终使用安全摘要，源日志保持不变。

更新已有安装后，请完整退出并重新打开 Codex，以加载新入口。

安装、截图、使用和隐私说明见[中文 README](../../README.zh-CN.md)。技术细节见[接口文档](../../docs/interface.md)和[原生查看器指南](../../docs/native-viewer.md)。
