# Codex Trajectory plugin

This directory is the installable Codex plugin. Repository-level installation, privacy, interface, development, and attribution documentation lives in the [project README](../../README.md).

Pricing is projected at task, turn, and Token-usage-record granularity. The live side panel shows the task and current-turn totals, sticky per-turn summaries, and the estimate on every Token-bearing event card; native PiP mirrors the task, turn, and latest-record estimates.

The MCP runtime reads only descriptor-checked plain or Zstandard-compressed files under authorized local Codex session roots, validates legacy and paginated rollout lineages, excludes linked files and inherited subagent prefixes, and defaults to safe summaries. Use the plugin through its bundled Skill or the `list_codex_sessions`, `get_codex_trajectory`, and `show_codex_trajectory` tools. Historical queries use a bounded, signature-validated local metadata index before full overviews are built, and the viewer loads its recent-session selector only after rendering the selected trajectory. The viewer reports total and per-turn standard-API-equivalent USD cost estimates with explicit pricing coverage; these are not Codex subscription charges. It also has an adaptive live window backed by an app-only safe-summary update tool: Codex gets a full-height side panel with frozen task totals, a remaining-quota badge, one-click and optional threshold stop controls, and a scrolling per-record Token stream, while regular Chromium pages can use native video PiP. Stop controls require the experimental loopback CDP opt-in. The standard Apps surface calls an app-private, model-hidden stop tool that pauses an active Goal and interrupts the active App Server turn directly without posting a follow-up message, invoking the model, opening the confirmation dialog, entering the steering queue, or touching composer drafts and attachments. Manual Stop rearms for a later running turn, while automatic Stop stays latched across later turns in the same quota cycle; stale turns rebind once and transient failures retry. When direct CDP is unavailable or a different trajectory is selected, the controls fail closed. On macOS and Windows, the token-bearing in-app Browser shortcut is restored only after each CDP connection is bound to the authenticated Codex desktop host by operating-system TCP ownership plus signing or package checks; failures and unsupported platforms remain fail-closed. After one-time hook review, an asynchronous session-start bootstrap restores an already enabled watcher earlier, while MCP startup remains the fallback. Public trajectory tools remain read-only; private local actions are constrained to plugin-owned CDP settings or the exact bounded task stop. Protocol, projection, privacy, and resource limits are documented in the [interface reference](../../docs/interface.md).
