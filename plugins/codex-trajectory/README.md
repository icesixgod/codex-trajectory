# Codex Trajectory plugin

This directory is the installable Codex plugin. Repository-level installation, privacy, interface, development, and attribution documentation lives in the [project README](../../README.md).

The MCP runtime reads only authorized local Codex session roots, validates legacy and paginated rollout lineages, excludes linked files and inherited subagent prefixes, and defaults to safe summaries. Use the plugin through its bundled Skill or the `list_codex_sessions`, `get_codex_trajectory`, and `show_codex_trajectory` tools. The viewer also has an adaptive live window backed by an app-only safe-summary update tool: Codex gets a full-height side panel with frozen task totals and a scrolling per-record Token stream whose compact rows group Total, Input, and Output usage, while regular Chromium pages can use native video PiP. The mounted Codex shell is patched in place between one-second checks to keep its status row stable. Neither path launches a standalone app. Protocol, projection, privacy, and resource limits are documented in the [interface reference](../../docs/interface.md).
