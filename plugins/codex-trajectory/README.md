# Codex Trajectory plugin

This directory is the installable Codex plugin. Repository-level installation, privacy, interface, development, and attribution documentation lives in the [project README](../../README.md).

The MCP runtime reads only authorized local Codex session roots and defaults to safe summaries. Use the plugin through its bundled Skill or the `list_codex_sessions`, `get_codex_trajectory`, and `show_codex_trajectory` tools.
