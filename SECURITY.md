# Security Policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that may expose local task content or escape the authorized Codex session directories. Use GitHub's private vulnerability reporting for this repository. Include the affected version, platform, reproduction steps, and expected impact. You should receive an acknowledgement within seven days.

## Security model

All trajectory and live-update tools are read-only and accept session identifiers rather than file paths. They resolve each configured root, then discover only regular, single-link descendant files below the active or archived root; descendant symbolic links, file hardlinks, root escapes, ambiguous ID prefixes, and inconsistent paginated lineage boundaries fail closed. Session and JSON-RPC inputs have byte, collection, nesting, and numeric conversion bounds, and public filesystem failures do not include local paths. The only writing tool is app-private and limited to atomic mode-0600 CDP settings/heartbeat files below the plugin-owned `CODEX_HOME/codex-trajectory` directory; it refuses symbolic-link destinations and never writes task history.

Safe summary mode excludes raw inputs, outputs, metadata, base instructions, and encrypted reasoning. Full details remain bounded and still exclude base instructions and encrypted reasoning, but the plugin cannot protect content after a user explicitly loads those details into a Codex conversation. The viewer uses a restrictive Content Security Policy, escapes log-derived markup, and times out unanswered host requests.

The experimental CDP injector is disabled by default, allows only loopback HTTP/WebSocket endpoints, refuses HTTP redirects during discovery, bounds HTTP/WebSocket messages and target counts, and applies an absolute deadline to each WebSocket command. It evaluates the token-bearing injector only in Codex-owned `app://` renderers, removes stale injection state from other targets, and tries every eligible renderer before reporting that the bridge is unavailable. Its settings, heartbeat, and process-lock reads reject symbolic links, hardlinks, non-regular files, and oversized content; runtime replacement asks the verified old watcher to exit through its private setting instead of signaling a possibly reused PID. Its separate local viewer binds an ephemeral `127.0.0.1` port, requires a random in-memory 256-bit path token and exact loopback Host header, disables caching, and applies restrictive parent/viewer Content Security Policies. The tool bridge accepts at most 64 KiB of interoperable JSON per call and allowlists only trajectory reads/updates plus the plugin-owned CDP setting/status tools; the viewer defaults to safe summary and requires explicit confirmation for bounded full details. Its read-only theme route returns an exact key set of bounded CSS colors from a fixed Codex-property allowlist, accepts no caller-supplied selector or property name, and rejects non-color values before they reach the viewer. A separate read-only task-state route requires an exact bounded session identifier and returns only a boolean plus a bounded turn identifier or null. Routine checks confirm task activity without turn history; when `turn/interrupt` rejects a stale projected candidate, the wrapper invalidates it and performs one full bootstrap before a retry. The stop route rejects arbitrary prompts and accepts only an exact bounded session and turn identifier, fixed source enum, integer threshold, and locale. It pauses an active Goal before calling `turn/interrupt` with those exact identifiers, and never reads or writes composer content or attachments. CDP itself grants broad control over the application renderer to any local process that can reach the debugging port; users must never bind or forward that port beyond loopback. Codex DOM or App Server bridge changes can break the integration, but unmatched pages remain unchanged and disabling the feature removes its node, closes the viewer server, and stops its watcher.
